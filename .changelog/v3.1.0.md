# Version 3.1.0

## New digit operations

`Digit` gains 27 binary `const fn` methods. Each takes two digits and returns a
`Digit`. All are available with default features disabled and can be passed to
`DigitOperate::each_zip` for digitwise operations on ternary words.

| Family                    | Methods                                                                                                    |
|---------------------------|------------------------------------------------------------------------------------------------------------|
| Three-valued logic        | `l3_strong_and`, `l3_strong_or`, `rm3_fusion`, `mc_and`, `mc_or`                                           |
| Comparison and distance   | `compare`, `equal`, `different`, `lesser`, `lesser_or_equal`, `greater`, `greater_or_equal`, `graded_diff` |
| Agreement and combination | `consensus`, `unknown_consensus`, `compatible`, `accept_anything`, `coalesce`, `exclusive_merge`           |
| Selection and control     | `duel`, `third`, `enable`, `inhibit`                                                                       |
| Steps and cyclic order    | `step_toward`, `step_back`, `is_successor`, `is_predecessor`                                               |

`compare` returns the sign of the comparison in the order `Neg < Zero < Pos`.
The six equality and ordering predicates return `Pos` for true and `Neg` for
false. For example, `Zero.compare(Zero)` yields `Zero`, while
`Zero.equal(Zero)` yields `Pos`.

## Boolean conversion

`Digit::try_to_bool()` is a new `const fn` returning `Option<bool>`.
It maps `Neg` to `Some(false)`, `Zero` to `None`, and `Pos` to `Some(true)`.
`Digit::ht_bool()` still panics on `Zero`. Its panic message now points to
`try_to_bool()`.

## Documentation and tests

The README truth-table diagram now includes all 27 new operations. Tests cover
all 426 entries across the 13 unary and 43 binary operations in the diagram,
including the three divisions by zero that must panic.
