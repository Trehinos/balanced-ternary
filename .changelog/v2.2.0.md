# Version 2.2.0

|                  | ------------------------------- |
|------------------|---------------------------------|
| Label            | Arithmetic and correctness      |
| Type             | Fixes and API enhancements      |
| Publication date |                                 |

## Fixed

- Corrected `Digit` subtraction modulo 3.
- Fixed `Ternary::checked_to_dec()` for signed 64-bit boundary values, including `i64::MIN`.
- Removed unnecessary integer conversion from `Ternary::trim()`.
- Enforced the signed 40-trit range in `Ter40` constructors and arithmetic operators.

## Added

- Checked arithmetic methods for `Ter40`.
- Wrapping, checked, overflowing and saturating addition, subtraction and multiplication for `Tryte<N>`.
- Explicit carry-returning operations for `Tryte<N>` and `Ter40`.
- Modular inversion and modular division for `Tryte<N>`.
- Additional arithmetic boundary and regression tests.

## Changed

- `Tryte<N>` addition, subtraction and multiplication now wrap modulo 3^N.
- `Tryte<N>` division uses signed integer division with truncation toward zero.
- `Tryte<N>` retains wrapping, overflowing and saturating division helpers for API consistency.
- Updated documentation of fixed-width arithmetic and overflow behavior.

## Compatibility

- The `DigitOperate` trait signatures remain unchanged.
- `Ter40` constructors now reject values outside the representable 40-trit range.
- Existing `Tryte<N>` arithmetic expressions may produce different results on overflow.
